# Product Specification: CallScreen AI
## AI Phone Screening for Frontline Hiring

### Overview
CallScreen AI is an intelligent voice screening platform purpose-built for high-volume blue-collar and frontline staffing. Using CALL-E telephony agents, CallScreen AI turns manual recruiter phone queues into automated, structured candidate scorecards.

### Key Workflows
1. **Job & Screening Configuration**:
   - Set up job specifications (Shift, Location, Target Salary, Experience).
   - Configure 5 concise voice screening questions.
2. **Batch Import & Dial Confirmation**:
   - Import candidates via CSV or quick entry.
   - Recruiter reviews candidate phone numbers and confirms batch size before placing outbound calls.
3. **CALL-E Autonomous Voice Screening**:
   - Outbound voice agent connects with candidates via phone.
   - Asks screening questions naturally, collects answers, handles hesitations.
4. **Structured Scorecard & Recruiter Decision**:
   - Ingests verbatim transcript.
   - Extracts structured criteria (Shift fit, Commute distance, Salary match).
   - Displays clear recommendation tags (`Qualified`, `Maybe`, `Not Fit`) for human recruiter review.
