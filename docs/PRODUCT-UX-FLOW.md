# CallScreen AI — Product UX Flow & Mental Model

```text
[ Applicant Queue ] ──► [ Job Screening Specs ] ──► [ AI Phone Screening (CALL-E) ]
                                                                │
                                                                ▼
                                                    [ Live 2-Way Voice Dialog ]
                                                                │
                                                                ▼
                                                    [ Verbatim Speech Transcript ]
                                                                │
                                                                ▼
                                                    [ Deterministic 5-Point Extraction ]
                                                                │
                                                                ▼
                                                    [ Evidence-Based Scorecard ]
                                                                │
                                                                ▼
                                              [ Qualified / Needs Review / Not Qualified ]
                                                                │
                                                                ▼
                                              [ Human Recruiter Final Hiring Decision ]
```

### Core UX Tenets:
1. **CALL-E is the Engine, CallScreen AI is the Product.**
2. **AI is the Scribe & Screening Assistant; the Human Recruiter Makes the Final Hire.**
3. **Evidence-First:** Every qualification metric links directly to spoken words in the transcript.
4. **Safety-First:** E.164 verification and confirmation modals guarantee no accidental live dials.
